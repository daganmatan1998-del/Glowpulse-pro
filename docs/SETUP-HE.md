# GlowPulse — מדריך הקמה מהיר

> החנות עצמה כולה באנגלית. המדריך הזה בעברית רק כדי שיהיה נוח להתקין. המדריך המלא באנגלית נמצא ב־[SETUP.md](SETUP.md).

---

## 1. התקנת התבנית

**אפשרות א׳ — קובץ zip:**

```bash
./scripts/package.sh
```

נוצר `glowpulse-theme.zip`. בשופיפיי: **Online Store → Themes → Add theme → Upload zip file**, ואז **Publish**.

**אפשרות ב׳ — Shopify CLI (מומלץ בזמן עריכה):**

```bash
npm install -g @shopify/cli @shopify/theme
shopify theme dev --store fdbp1y-1n.myshopify.com
```

## 2. תפריטים

**Online Store → Navigation.** צריך שני תפריטים:

- `main-menu` — Shop, Best sellers, Reviews, About, Contact
- `footer` — FAQ וכל דפי המדיניות

## 3. דפים

**Online Store → Pages.** לכל דף יש לבחור **Theme template** בצד ימין:

| שם הדף | Handle | Template | תוכן |
| --- | --- | --- | --- |
| Reviews | `reviews` | `page.reviews` | להשאיר ריק |
| FAQ | `faq` | `page.faq` | להשאיר ריק |
| About | `about` | `page.about` | להשאיר ריק |
| Contact | `contact` | `page.contact` | להשאיר ריק |
| Shipping Policy | `shipping-policy` | `page.policy` | להעתיק מ־`docs/policies/shipping-policy.md` |
| Refund Policy | `refund-policy` | `page.policy` | להעתיק מ־`docs/policies/refund-policy.md` |
| Privacy Policy | `privacy-policy` | `page.policy` | להעתיק מ־`docs/policies/privacy-policy.md` |
| Terms of Service | `terms-of-service` | `page.policy` | להעתיק מ־`docs/policies/terms-of-service.md` |

חשוב: למלא גם את **Settings → Policies**. שופיפיי מקשר לשם מהצ׳קאאוט, וספקי תשלום דורשים את זה.

בקבצי המדיניות יש מקומות שמסומנים כך: `{{ support@yourstore.com }}`. צריך לחפש `{{` ולוודא שלא נשאר אף אחד לפני העלאה לאוויר.

## 4. ייבוא מוצר מ־DSers

1. להתקין **DSers** מה־App Store ולחבר לחנות.
2. להתקין את התוסף של DSers לכרום.
3. למצוא מוצר באלי אקספרס וללחוץ על הכפתור של DSers — המוצר נכנס ל־**Import List**.
4. **לפני** שדוחפים לשופיפיי, בתוך ה־Import List:
   - **לשכתב את השם.** השמות של אלי אקספרס הם ערימת מילות מפתח. עדיף "Ceramic Swirl Mug — 350ml".
   - **למחוק וריאציות מיותרות.** הספק מעלה 40 צבעים. להשאיר 3–6.
   - **לשנות שמות אופציות.** למחוק `Ships From` — הלקוח לא צריך לראות את הלוגיסטיקה של הספק.
   - **לקבוע מחיר.** ב־DSers יש Pricing Rule אוטומטי. מכפיל של 2.5–3 זו נקודת פתיחה נפוצה.
   - **לנקות את התיאור.** למחוק את ה־HTML של הספק ולכתוב שתיים־שלוש פסקאות אמיתיות. להשאיר רק תמונות בלי כיתוב בסינית.
5. לדחוף לשופיפיי.

**אחרי הייבוא**, בכרטיס המוצר בשופיפיי:

- **Media** — התמונה הראשונה היא זו שמופיעה ברשת. לסדר מחדש.
- **Variants → images** — אם לכל צבע יש תמונה, התבנית הופכת את בורר הצבע לעיגולי תמונה אוטומטית. שווה להקצות תמונה לכל וריאציה.
- **Collections** — חובה לשייך את המוצר לקולקציה, אחרת הרשת בדף הבית ריקה.

## 5. דף הבית

**Online Store → Customize.** דף הבית מגיע עם 11 סקשנים מוכנים — Hero, רצועה נעה, יתרונות, רשת מוצרים, סיפור, איך זה עובד, טבלת השוואה, ביקורות, גלריה, שאלות נפוצות, ניוזלטר.

הסקשן היחיד שדורש פעולה זה **Product grid** — צריך לבחור בו קולקציה.

## 6. ביקורות בלי אפליקציה בתשלום

הביקורות בנויות בתוך התבנית. כל ביקורת היא בלוק בעורך עם דירוג, כותרת, טקסט, שם, מדינה, תאריך, תגית "verified purchase" ותמונה.

בדף הביקורות יש גם ציון ממוצע והתפלגות כוכבים — שניהם **מחושבים מהביקורות שהזנת**, כך שהמספר תמיד תואם למה שהגולש באמת רואה.

אם בהמשך תתקין אפליקציית ביקורות (Judge.me, Loox, Okendo), התבנית קוראת אוטומטית את שדות המטא הסטנדרטיים `reviews.rating` והדירוגים האמיתיים מחליפים את ברירת המחדל בכל מקום. לא צריך לשנות כלום.

הערה שכדאי להתייחס אליה ברצינות: שדות ברירת המחדל לדירוג קיימים כדי שחנות חדשה לא תיראה ריקה, אבל להציג מספר ביקורות שלא באמת קיבלת זו עסקה גרועה. עדיף להשאיר את מספר הביקורות על 0 עד שיש אמיתיות.

## 7. צבעים, פונטים ואנימציות

**Customize → Theme settings** — צבעים, טיפוגרפיה, רוחב עמוד, עיגול פינות, עומק צללית, וסגנון האנימציה (fade / rise / zoom / blur) והמהירות שלה.

כל האנימציות נכבות אוטומטית אצל גולשים שהפעילו "reduce motion" במכשיר.

## 8. צ׳ק ליסט לפני עלייה לאוויר

- [ ] כל ה־`{{ }}` בדפי המדיניות הוחלפו
- [ ] **Settings → Policies** מלא
- [ ] כתובת מייל תמיכה אמיתית שקוראים אותה
- [ ] **Settings → Shipping and delivery** מוגדר (משלוח חינם דורש תעריף של 0, זה לא אוטומטי)
- [ ] ספק תשלום מחובר והזמנת בדיקה עברה
- [ ] זמני המשלוח בדף המוצר תואמים למה שהספק באמת מספק
- [ ] לוגו ו־favicon הועלו
- [ ] בדיקת צ׳קאאוט מלאה מהנייד, לא רק מהמחשב
- [ ] הסרת דף הסיסמה ב־**Online Store → Preferences**
